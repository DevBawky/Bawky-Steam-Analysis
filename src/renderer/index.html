활용 소스

  • Steam Web API / Store API앱 목록, 기본 메타데이터, 장르, 출시일 후보를 수집합니다.

  • SteamDB Snapshot공개 API가 아니므로 약관을 준수한 로컬 스냅샷 또는 자체 재수집 결과로 다룹니다.
  • VG Insights구독형 API를 통해 추정 판매량, 리뷰, 지역/시장 지표를 보강하는 소스로 가정합니다.

커버리지란?

커버리지는 목표 데이터셋 중 유효하게 교차 검증 가능한 레코드의 비율입니다. 예를 들어 Steam 앱 목록 10,000개 중 게임으로 판정되고, 최소 2개 이상 소스에서 주요 지표가 확보된 항목이 9,300개라면 커버리지는 93%입니다.

소스별 역할

소스 잘 쓰는 지표 주의점
Steam API 공식 앱/장르/출시 정보 성과 지표는 제한적입니다.
SteamSpy 태그, 리뷰, 소유자 추정 소유자 수는 범위 추정값입니다.
SteamDB 동시 접속자와 피크 추세 공식 공개 API가 아니므로 스냅샷 기반으로 다룹니다.
VG Insights 판매량과 시장 성과 추정 유료/추정 데이터라 검증 가중치를 둡니다.

교차 검증 파이프라인

  1. 여러 소스에서 동일 appId의 메타데이터와 성과 지표를 수집합니다.
  2. 태그 우선순위 규칙으로 하이브리드 장르를 먼저 확정합니다.
  3. 결측치는 제외하고, 중앙값 절대 편차 방식으로 극단값을 제거합니다.
  4. 소스별 신뢰 가중치를 적용해 수요/공급/종합 점수를 평균화합니다.
  5. 지역별 막대 합계가 정확히 100%가 되도록 반올림 오차를 보정합니다.

현재 앱 상태

현재는 네트워크 수집을 실제로 수행하지 않는 로컬 목업입니다. UI와 파이프라인 구조, 이상치 제거, 평균화, 장르 우선순위, 100% 누적 렌더링을 검증하기 위한 단계입니다.
